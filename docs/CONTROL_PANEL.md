# 真实微信测试控制台

## 启动与当前状态

```powershell
& E:\project\bot\.conda\python.exe E:\project\bot\scripts\control.py
# 使用模型、群前缀等来自指定配置的设置：
& E:\project\bot\.conda\python.exe E:\project\bot\scripts\control.py --config E:\project\bot\config\wechat.local.toml
```

窗口提供联系人/群聊绑定、白名单、只读检查、开启 Bot、关闭 Bot/紧急停止。
本地指定测试联系人的待校准绑定放在 `data/control/bindings.json`，不提交 GitHub。
未启用前不会连接微信；只读检查只访问已选择的独立窗口，不输入文字或点击发送。
取消 Echo 后使用启动配置中的模型；若该配置本来就是 Echo，仍然是 Echo。

**当前客户端尚未具备已验证的收发配置。** 2026-09-09 再次只读检查时，仅发现微信主窗口，
可访问性树仍只有窗口及两个窗格，没有返回消息列表、输入框或发送控件。
控制台没有通过坐标输入、临时消息序号或昵称猜测绕过这一限制。
它已具备调用真实 UIA 收发的接口，但不能据此声称当前微信已收发成功。

## 配置白名单

1. 人工登录微信，把专用测试联系人或群打开为独立窗口。
2. 点击「新增绑定」或「编辑绑定」，填写精确 PID、独立窗口标题、会话头和控件 AutomationId。
   发送者和消息 ID 必须稳定，时间必须为带时区 ISO 时间；核验方法见 `WECHAT_ADAPTER.md`。
   `会话唯一 ID` 是本地配置键，不能单独证明微信身份。窗口标题是定位辅助，也不是唯一身份凭证。
3. 可以先保存不完整绑定；其状态为「待校准」。只有人工确实核验后才勾选校准确认。
   编辑绑定会重置确认，导入 TOML 会重置所有确认并清空白名单。
4. 选中对应行，点「加入 / 移出白名单」或双击。联系人与群聊分类型匹配；没有全选默认项。
5. 点击「只读检查」。它核验窗口、消息结构、草稿和发送接口能力；不证明跨重启 ID 稳定或对端收到。
6. 保持 Echo，点击「开启 Bot」。启动会再次检查，并以当前可见消息建立基线。
   然后由专用测试账号发送新消息进行联调。首次基线以前的消息不会补发。
7. 点击「关闭 Bot / 紧急停止」，等待显示「已关闭」后再修改白名单。

群聊沿用配置中的 `rules.group_prefix`（默认 `/问 `）；UIA 不推断真正 @。
白名单按配置 ID 和 private/group 匹配，绝不把消息正文里出现昵称当作授权。
关闭、重开程序仅保存白名单和绑定，不保存开启状态。

## 隔离设计

| 层次 | 行为 |
|---|---|
| 配置 | 空白名单、未登记 ID、重复 ID、未校准或占位字段拒绝启动 |
| 读取 | 构造适配器前过滤 chats，只读取选中的窗口；其他会话不会进入模型或数据库 |
| 定位 | 精确 PID+标题、会话头、固定 HWND；窗口重建拒绝继续 |
| 写入 | 输入文本及 Invoke 两处经过同一个线程锁和开关检查，并重新校验目标窗口 |
| 界面 | 不搜索联系人、不切换主窗口聊天、不使用坐标、快捷键或剪贴板发送 |
| 关闭 | 先撤销许可，再等待已开始任务完成；已在执行的原生调用不能撤回 |
| 故障 | 轮询失败、最终发送失败或 uncertain 自动停止；不静默恢复发送 |
| 重启 | 每次开启新建独立数据库和历史，旧 run 的待发送任务永不恢复 |
| 实例 | 同一控制目录的 panel.lock/session.lock 阻止第二个面板/会话并发运行 |

运行中绑定编辑及白名单切换禁用。移出白名单的流程是关闭、移除、再开启新会话。
窗口关闭按钮同样先停止；若 Windows UIA 调用挂起，界面保持「正在停止」，不虚报已关闭。
已生成但尚未发送的任务不会绕过开关。停止后已开始的发送可能完成，需人工核对。

边界：无法对客户端缺陷、错误的人工身份标定、恶意同名窗口或已经提交的发送作绝对零影响保证。
测试期间不要手动改动被绑定的独立聊天窗口或其草稿，其他聊天无需供 Bot 使用。
独立窗口并不提供协议级稳定身份；若客户端不暴露必要字段，本接入必须保持禁用。
UIA 不提供完整离线消息流，停机/虚拟列表未加载消息可能漏收。
本地 `uia_visible` 回执也不代表对端已收；实际联调需由对端确认。

## 文件与测试

- `src/wechat_bot/control.py`：默认关闭的 SessionGate、受控 UIA 适配器和运行生命周期。
- `src/wechat_bot/panel.py`：本地 Tk 面板，不开放 HTTP 端口。
- `scripts/control.py`：直接使用项目环境启动。
- `data/control/allowlist.json`、`bindings.json`：本地配置，不含 API 密钥，Git 忽略。
- `data/control/runs/<随机ID>/`：本次 SQLite、心跳。聊天内容不进入 GUI；本地数据库需妥善保管。
- `tests/test_control.py`：白名单隔离、默认关闭、停止竞态、窗口重建、只读生命周期等。
- `tests/test_panel.py`：GUI 默认关闭、白名单保存/删除；无图形桌面的 Linux 会跳过该项。

运行 `scripts/wechat_test.py` 可复测全部项目；不会真实发送微信消息。
控件接口依据：[pywinauto 官方入门](https://pywinauto.readthedocs.io/en/latest/getting_started.html)、
[UIA 控件 API](https://pywinauto.readthedocs.io/en/latest/code/pywinauto.controls.uia_controls.html)。
