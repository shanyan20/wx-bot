## 当前各入口的用途

| 入口 | 运行方式 | 适用范围 |
|---|---|---|
| scripts/chat.py | 命令行好友模拟 | 模型/上下文调试，非真实微信 |
| python -m wechat_bot | mock 内核/队列工具 | 离线与模型测试、运维 |
| scripts/control.py | 原 UIA 模板控制台 | 旧严格 UIA 契约；不能用数据库列名填 AutomationId |
| scripts/acceptance.py | **本次真实微信验收入口** | 数据库入站、UIA 出站、每阶段人工判定 |
| scripts/acceptance_preflight.py | 只读文字/图片预检 | 仅指定测试窗口；不调用模型、不发送、不替人工判定 |
| scripts/acceptance_reconcile.py | 中断发送的只读核对 | 匹配出站后恢复为 C 待审阅，绝不重发 |

原有内核没有删除或替换；新验收工具单独保存 reviews.sqlite3，避免把正式
deepseek.sqlite3 的历史队列直接接到真实微信。

## 源码与任务映射

- acceptance.py：样本、阶段门禁、人工判定标志、审阅日志、隔离历史、异常恢复。
- acceptance_panel.py：白名单、独立页签、A/B/C 输出、确认窗口及导出。
- acceptance_setup.py：用户点击校准后，限定独立窗口执行校准脚本。
- adapters/native_review.py：目标验证、消息基线、自发消息过滤、输入/发送/出站核对。
- adapters/native_media.py：会话目录与消息摘要定位图片、解码与尺寸限制。
- adapters/native_identity.py：原生消息键；不是正文哈希或 UIA RuntimeId。
- adapters/sqlcipher_snapshot.py：页 HMAC、WAL 提交边界和内存快照。
- services/model.py、services/vision.py：DeepSeek 请求及真实图片 content block。

## 仍需保留的边界

1. 人工通过不能由自动测试代替；群聊/多联系人实际验收必须使用用户选择的测试窗口。
2. 图片读取依赖真实媒体、客户端状态与受支持格式；失败时显示原因并阻止 A 通过。
3. PID、句柄、密钥绑定在微信重启后需要重新校准；不自动搜索或切换其他聊天。
4. 数据库还原/重建/迁移、极端并发写入及新分片不是本版已全面验证的生产能力。
5. 不确定发送必须核对；本地出站证据不等于服务器交付或对方已读。
