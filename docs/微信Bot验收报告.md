## 2. 本版交付范围

- 中文启动/停止面板，独立窗口白名单，按会话分列及上下文隔离。
- 原生消息键、历史基线、自发消息过滤、文字与条件性图片读取。
- A 读取、B 模型、C 草稿/发送分别执行，展示输出及人工确认窗口。
- 草稿保护、停止屏障、中断恢复、出站证据和本地事件记录。
- 微信当前进程校准、只读样本预检和未确定发送状态的只读核对工具。
- 中文项目说明、历史版本整理、完整测试步骤及本报告。

当前实现是保留人工审阅的验收流程；不提供跳过审阅的无人值守自动发送。

## 5. 本次问题与修复

图片初次读取把 WXGF/HEVC 封装误归为不支持图片或密钥失败。
加入封装识别、目标图片完整解码验证及 HEVC 到 PNG 转换后，真实样本读取成功。
不以占位图、聊天截图或其他会话图片替代失败样本。

程序中断后的 `sending` 记录先转为 `uncertain`，只读核对唯一匹配后转为 `c_review`。
核对脚本没有重新发送，也没有设置 C 人工通过标志。

## 6. 本地证据位置

以下文件含私有内容，仅保存在本地，未纳入 Git：

- `data/acceptance/reviews.sqlite3`：阶段、人工标志、模型回复、出站证据及事件表。
- `data/acceptance/read-preflight.json`：真实文字/图片只读预检。
- `data/acceptance/media/`：已解码的样本图片。
- `data/acceptance/review-*.json`：测试人员从面板导出的逐条验收报告。
- `data/db-probe/keys.dpapi`：当前用户保护的本地绑定及密钥材料。

公开报告不包含真实消息正文、账号 ID、图片、模型完整回复或密钥。

## 7. 剩余验收及复测方法

按 [完整测试说明](微信Bot完整测试说明.md) 执行：

1. 启动验收面板，选中 shanyan 并连接，查看恢复的文字 `c_review` 样本。
2. 在微信核对对应已发送内容，再由测试人员决定 C 是否通过；不要重复发送。
3. 点击“A 最近图片”，核对真实预览，依次人工完成 A、B、C。
4. 用专用联系人/群完成白名单外观察、会话隔离、停止、重启及草稿保护测试矩阵。
5. 导出本地验收报告，记录每项实际结果与人工判定。

模型、图片解码与轮询共用工作线程，不承诺硬实时。底层 UIA 调用可能阻塞，
停止按钮阻止后续动作，但不能撤销已提交的发送或保证立即终止阻塞调用。
图片格式、当前微信版本之外的客户端和群控件结构仍需实机验证。
