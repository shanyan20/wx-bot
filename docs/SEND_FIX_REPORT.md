## 诊断

本轮只读检查发现发送按钮是 Qt UIA 控件，没有独立 HWND；检查时输入为空、按钮禁用。
没有填入调试内容或代用户发送消息。

## 修改

- 自动调度只允许读取→模型→草稿；代码不会由调度器进入发送状态。
- 同一聊天的待确认/不确定发送会阻止下一条自动草稿，避免覆盖。
- 按钮仍通过白名单、PID、进程启动时间、HWND、原生会话身份、标题及精确控件属性校验。
- 发送采用限定 HWND 的 WM_LBUTTONDOWN/WM_LBUTTONUP；坐标由本次 UIA 按钮区域
  转成客户区坐标，不固定屏幕坐标，不抢键盘焦点，不移动全局指针。
- 发送前再次核对草稿，按钮不可用或位置越界时拒绝投递。
- 一次确认只触发一组按下/抬起；窗口调用设置超时，不自动转 Invoke/回车重试。
- 发送回执绕过快照缓存并重读数据库；并发快照冲突只重试只读检查。
- 同文比较统一 CRLF/LF；仍要求新增、本账号发送、文本一致且唯一。

Win32 客户区坐标语义参考
[WM_LBUTTONDOWN 文档](https://learn.microsoft.com/en-us/windows/win32/inputdev/wm-lbuttondown)。
窗口是否实际处理这组事件仍需实机确认，不能把 Win32 调用返回当成发送成功。
